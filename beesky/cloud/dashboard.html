Agent & trại

Mỗi trại chạy một chương trình agent trong mạng nội bộ của trại: agent quét các máy đào rồi tự đẩy số liệu lên cloud này. Tạo agent ngay tại đây — không cần chạy lệnh beesky cloud-add-agent trên máy chủ nữa. Key của agent chỉ hiện một lần lúc tạo; cloud chỉ lưu bản băm SHA-256. Thu hồi một agent = key của nó bị vô hiệu ngay, agent ở trại sẽ không đẩy dữ liệu lên được nữa.

Key chỉ hiện MỘT lần này — copy lưu lại ngay, cloud chỉ giữ bản băm SHA-256 nên không xem lại được.

So sánh pool — cấu hình theo trại

Khai báo API của pool để cloud đối chiếu hashrate của trại với số pool ghi nhận (lệch kéo dài sẽ sinh sự kiện POOL_GAP). Adapter generic đọc một URL JSON bất kỳ, lấy hashrate theo đường dẫn chấm — vd URL https://pool.example.com/api/stats, đường dẫn data.hashrate. Preset emcd tự điền URL / đường dẫn mẫu của EMCD khi để trống; hãy đối chiếu tài liệu API của EMCD rồi sửa lại cho đúng tài khoản của bạn.

Giá trị headers là bí mật (API key của pool): cloud chỉ lưu để gọi pool, không bao giờ hiển thị lại — phần “Cấu hình hiện tại” bên dưới chỉ liệt kê tên header đã đặt. Để trống ô này khi lưu = giữ nguyên headers đã lưu trước đó; muốn thay thì nhập lại JSON mới.
